# Lab 5 – Automation (eBay)

How to run:
1) Open this folder in IntelliJ IDEA.
2) When prompted, *Load as Maven project* (or right‑click `pom.xml` → Maven → Reload).
3) Open `src/test/java/md/utm/isa/lab5/EbaySearchHeaderTest.java` and click Run ▶,
   or run from terminal: `mvn test -Dtest=EbaySearchHeaderTest` (if Apache Maven is on PATH).
